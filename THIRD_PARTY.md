# Third-party software
LiteLAN is an independent native frontend, not an official AnywhereLAN release.
The build fetches an unmodified AnywhereLAN v0.21.0 binary, MPL-2.0:
https://github.com/anywherelan/awl/tree/v0.21.0
License: https://github.com/anywherelan/awl/blob/v0.21.0/LICENSE
Source: https://github.com/anywherelan/awl/archive/refs/tags/v0.21.0.zip
The original archive's files are preserved in the core folder. Rust dependencies are listed in Cargo.toml; their respective licenses apply.
